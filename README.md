# Amazon-Sales-SQL-Analysis
Amazon Sales Data Analysis using PostgreSQL, CTEs, Subqueries and Window Functions.

📌 Project Overview
This project analyzes Amazon sales data using PostgreSQL to identify revenue trends, customer behavior, product performance, and geographical sales patterns.

🛠 Tools Used
- PostgreSQL
- CSV Dataset

📊 Dataset Information
- Records: 128,975
- Domain: E-commerce Sales

🔍 Business Questions Solved
- Total revenue generated
- Revenue by category
- Top states by revenue
- Cancellation rate
- B2B sales contribution
- Monthly revenue trends
- Top-selling categories
- Revenue contribution analysis

🧠 SQL Concepts Used
- Joins
- Aggregate Functions
- GROUP BY & HAVING
- Subqueries
- CTEs
- Window Functions
- RANK()
- DENSE_RANK()
- LAG()

📈 Key Insights
- Total Revenue: ₹78,592,678.30
- Highest Revenue Category: Set (₹39,204,124.03)
- Highest Revenue State: Maharashtra (₹13,335,534.14)
- Highest Revenue Month: April (₹28,838,708.32)
- Cancellation Rate: 14.21%

🚀 Conclusion
This project demonstrates SQL-based data analysis techniques for extracting business insights from large-scale sales data.
